CONCEPTUAL DIAGNOSTIC · THEOREM 3.2 [Tutorial-3.pdf · Page 15, Equation 3.7]

Under what condition does the hazard function h(t) = f(t) / S(t) remain strictly constant for all t ≥ 0?

A

When the survival function S(t) decreases according to a power law t-α.

B

When X is exponentially distributed with constant arrival rate λ, yielding h(t) = λ.

VERIFIED
check_circle Archival Explanation

Correct. Since f(t) = λe-λt and S(t) = e-λt, their quotient h(t) = λ is independent of elapsed time t. This is the continuous manifestation of memorylessness.

C

When the probability density function is symmetric around the expectation μ.

Incorrect. Symmetry implies variable hazard rates unless variance is degenerate.

D

When the cumulative distribution function satisfies F(2t) = 2F(t).
