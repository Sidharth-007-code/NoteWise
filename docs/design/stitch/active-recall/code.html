Prove the Variance Formula for an Exponential Random Variable

For X ~ Exp(λ), show that Var(X) = 1 / λ2 starting from E[X2] = ∫0∞ x2 λ e-λx dx.
Proof Analytical Steps Step 1 & 2 Verification

Integration by parts yields E[X2] = 2 / λ2. Consequently, Var(X) = E[X2] − (E[X])2 = 2 / λ2 − 1 / λ2 = 1 / λ2.
