§ 3.2 Moment-Generating Functions

Let $X$ be a random variable with density $f_X(x)$. The expected value of $e^{tX}$ is termed the moment generating function, yielding the characteristic Taylor expansion:

M_X(t) = E[e^{tX}] = \sum_{k=0}^{\infty} \frac{t^k E[X^k]}{k!}
